C Compiler source

Jan 2025 — Jun 2025

C → Intel 8086 assembly, in C++17 and ANTLR 4

  • Translates a substantial subset of C into runnable Intel 8086 assembly via single-pass syntax-directed translation, with code-generation actions embedded directly in the parser grammar.
  • Full front end in four stages: a Flex/ANTLR lexer, a parser with semantic analysis (type checking, redeclaration and arity errors), and a scoped hash-based symbol table supporting shadowing and nested scopes.
  • 8086 back end with BP-relative stack frames for locals and parameters and callee cleanup via RET n — enabling recursive calls, one-dimensional arrays and arbitrarily nested control flow.
  • Peephole optimiser over the emitted assembly that eliminates redundant MOV sequences and PUSH/POP pairs left behind by stack-machine expression evaluation, reporting the instruction count saved.
Compilers C++17 ANTLR 4 x86 / 8086 Code generation
